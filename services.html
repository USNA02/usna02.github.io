Services

Four services. A file at the end of each.

Cleaning, SQL, exploration, and a report a non-specialist can use. Scoped so the same offer can sit on a freelance gig without a vague retainer.

01

Data Cleaning and Preparation

Cleaning, organising, formatting and preparing datasets so the analysis that follows is about the business, not about broken cells.

Excel, SQL, Python

Who it is for

Teams sitting on exports, forms, or workbooks that cannot be joined or trusted yet.

What to send

The file as it is, a note on what each important column should mean, and any total you already believe.

You leave with

  • A single cleaned table, with types and names that stay consistent
  • Duplicates, blanks, and format problems handled in the open
  • Row counts before and after
  • A short change log, so the next person knows what moved

02

SQL and Database Analysis

Querying relational databases, joining tables, aggregating information and extracting a business answer you can rerun.

SQL, PostgreSQL

Who it is for

Anyone who already has PostgreSQL, or a set of tables that should become one.

What to send

The question in one sentence, and access to a copy of the data or a description of the grain.

You leave with

  • Queries named for the question they answer
  • Joins and filters written so they can be read, not only run
  • A check against a total you already trust
  • The SQL saved with the finding

03

Exploratory Data Analysis

Examining a dataset for shape, gaps, and patterns before anyone commits to a chart or a decision.

Python, Pandas, SQL

Who it is for

A new extract, a public series, or a table you suspect is hiding a bad join.

What to send

The file and the decision you hope it can support. I will say if it cannot.

You leave with

  • Counts, ranges, and missingness before any story
  • Patterns stated in plain language
  • The comparison that actually shows the pattern
  • What the sample does not show

04

Data Reporting and Visualisation

A report, a workbook, or a small visual that a colleague can use without opening the notebook.

Excel, written reports, Power BI

Who it is for

Managers and operators who need the result, not the workflow that produced it.

What to send

The audience, the decision, and the one comparison that matters.

You leave with

  • The number inside a sentence
  • One chart per point, or none
  • The caveat in the same view as the result
  • A next step that is actually a step

Method

How a piece of work runs

  1. 01

    Name the decision the number has to support.

  2. 02

    Name the grain: one row is one what?

  3. 03

    Write the query or the script.

  4. 04

    Check it against a total you already believe.

  5. 05

    Say the result in a paragraph, including what it does not prove.
